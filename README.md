# psych

psych is a lightweight revision website for IB Psychology. It brings the course material together in a simple, searchable interface designed for quick study.

## What it includes

- Revision notes with supporting studies and evaluation
- Key terms grouped by course concept
- An exam-style question bank with search and filters
- A reusable prompt for AI-assisted answer marking
- Responsive, accessible layouts for desktop and mobile

## Tech stack

The site uses plain HTML, CSS, and vanilla JavaScript. It has no framework, package manager, build step, or runtime dependency. Google Fonts supplies the Onest typeface when an internet connection is available.

## Run locally

You can open `index.html` directly in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
